# AI a bezpieczeństwo organizacji

## Konspekt

Materiały z mojej prelekcji „AI a bezpieczeństwo organizacji” na wewnętrznej konferencji o bezpieczeństwie firmy BEST S.A.

## Opis prezentacji

Prezentacja pokazuje, jak AI staje się wektorem ataku i ilustruje to głośnymi incydentami z ostatnich lat. Przedstawia konkretne narzędzia obrony w AWS i Azure oraz zasady organizacyjne, które pozwalają bezpiecznie korzystać z AI w firmie finansowej.
